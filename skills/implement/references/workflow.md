# implement workflow

- plan、調査結果、既存差分、局所ルールを読む。
- 変更前に対象ファイル、実行環境、関連する agent skill の配置を確認する。
- 要求範囲に必要なファイルだけ変更する。
- 既存の命名、構成、依存、検証方法に合わせる。
- 該当する場合だけ `languages.md` の言語別注意事項を確認する。
- 無関係な整形、リファクタ、依存追加を避ける。
- テストコードの追加・修正も実装範囲に含めるが、検証コマンドは `test` に委譲する。
- plan にない変更、無関係な整形、リファクタ、依存追加を見つけたら範囲を広げず plan に戻す。
- 編集完了後は変更内容、未実行の検証、判断が必要な事項を `test` へ引き渡す。
